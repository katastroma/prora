# Prora

Tenant self-service frontend for [katastroma](https://github.com/katastroma).
Consumes the [grammateus](https://github.com/katastroma/grammateus) API.

## What It Does

Prora provides the UI for tenants to manage their own registrations, namespaces,
Applications, and RepoCredentials.

## Ecosystem

- **[Grammateus](https://github.com/katastroma/grammateus)** — the API server
- **Prora** (this) — the tenant self-service frontend
